The `ReasoningDuo` class implements a dual-agent reasoning system that combines a reasoning agent and a main agent to provide well-thought-out responses to complex tasks. This architecture separates the reasoning process from the final response generation.

## Architecture

```
Task Input → Reasoning Agent → Structured Analysis → Main Agent → Final Output
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `id` | `str` | `generate_id("reasoning-duo")` | Unique identifier for the duo (`<prefix>-<32 hex chars>`) |
| `agent_name` | `str` | `"reasoning-agent-01"` | Base name for the two internal agents, which are suffixed `-reasoning` and `-main` |
| `agent_description` | `str` | `"A highly intelligent..."` | Stored on the instance. It is handed to both internal agents as `description`, which `Agent` does not use |
| `model_name` | `str` | `"gpt-5.4"` | Stored on the instance; not currently used to configure either internal agent |
| `description` | `str` | `"A highly intelligent..."` | Stored on the instance; not used by either internal agent |
| `model_names` | `list[str]` | `["gpt-5.4", "gpt-5.4"]` | `model_names[1]` is the main agent's model. `model_names[0]` is used for the reasoning agent only when `reasoning_model_name` is `None` |
| `system_prompt` | `str` | `"You are a helpful..."` | System prompt for the main agent. The reasoning agent always uses the built-in `REASONING_PROMPT` |
| `output_type` | `OutputType` | `"dict-all-except-first"` | Format of the value returned by `run()` |
| `reasoning_model_name` | `Optional[str]` | `None` | Model used by the reasoning agent. `None` runs it on `model_names[0]`, or on `model_name` when `model_names` is not given, so a duo built on one provider stays on it |
| `max_loops` | `int` | `1` | Number of reasoning/main-agent loop iterations in `run()` |
| `*args`, `**kwargs` | | | Extra `Agent` arguments applied to both internal agents |

<Warning>
`reasoning_model_name` defaults to `None`, which runs the reasoning agent on `model_names[0]` (or on `model_name` when `model_names` is not given). Set it to put the reasoning agent on a different model.
</Warning>

### Methods

| Method | Parameters | Returns | Description |
|--------|------------|---------|-------------|
| `step` | `task: str, img: Optional[str] = None` | `None` | Runs one reasoning-agent → main-agent cycle and appends to the conversation |
| `run` | `task: str, img: Optional[str] = None` | Formatted per `output_type` | Starts a new conversation, then processes the task through both agents for `max_loops` iterations |
| `batched_run` | `tasks: List[str], imgs: Optional[List[str]] = None` | `list` | Processes multiple tasks sequentially. `imgs` pairs one image with each task and must be the same length as `tasks`, or `ValueError` is raised |

## How a run works

Each `run()` starts from an empty conversation, so one task never leaks into the next and every `batched_run` result holds only its own task. After a run, `duo.conversation` holds that run's messages.

In each loop, the reasoning agent (named `<agent_name>-reasoning`) answers first, then the main agent (`<agent_name>-main`) answers with the reasoning in front of it. Both agents read the shared conversation as chat turns: an agent's own earlier answers arrive as `assistant` turns and its partner's as labelled `user` turns. The first loop sends your task. Each later loop sends "Continue reasoning and refining your analysis."

## Quick Start

```python
from swarms import ReasoningDuo

duo = ReasoningDuo(
    agent_name="reasoning-agent-01",
    reasoning_model_name="claude-sonnet-4-6",
    model_names=["claude-sonnet-4-6", "gpt-5.4"],
)

result = duo.run("Explain the concept of gravitational waves")
```

## Examples

### Mathematical Analysis

```python
from swarms import ReasoningDuo

duo = ReasoningDuo()

math_task = """
Solve the following differential equation:
dy/dx + 2y = x^2, y(0) = 1
"""

solution = duo.run(math_task)
```

### Financial Analysis

```python
from swarms import ReasoningDuo

duo = ReasoningDuo()

finance_task = """
Calculate the Net Present Value (NPV) of a project with:
- Initial investment: $100,000
- Annual cash flows: $25,000 for 5 years
- Discount rate: 8%
"""

analysis = duo.run(finance_task)
```

### Customizing Agent Behavior

```python
from swarms import ReasoningDuo

duo = ReasoningDuo(
    agent_name="custom-reasoning-agent",
    reasoning_model_name="claude-sonnet-4-6",
    model_names=["claude-sonnet-4-6", "gpt-5.4"],
    system_prompt="You are a financial expert AI assistant...",
    output_type="final",
)
```

### Batch Processing

```python
from swarms import ReasoningDuo

duo = ReasoningDuo()

tasks = [
    "Analyze market trends for tech stocks",
    "Calculate risk metrics for a portfolio",
    "Forecast revenue growth"
]

results = duo.batched_run(tasks)
```

## Best Practices

1. **Task Formulation**: Be specific and clear in task descriptions. Include relevant context and constraints.
2. **Performance Optimization**: Use `batched_run` for multiple related tasks. Monitor agent outputs for consistency.
3. **Model Selection**: Adjust model parameters based on task complexity.
