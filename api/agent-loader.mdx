## Overview

The `AgentLoader` class provides a unified interface for instantiating `Agent` objects from on-disk definitions. It supports four file formats and dispatches automatically based on the file extension.

| Format | Extension | Backing method |
|---|---|---|
| Markdown | `.md` | `load_agents_from_markdown` |
| YAML | `.yaml`, `.yml` | `load_agents_from_yaml` |
| CSV | `.csv` | `load_agents_from_csv` |
| JSON | `.json` | `load_agents_from_csv` |

Extensions are matched in any case, so `TEAM.YML` and `team.yml` both load. `auto()` reads back every format `create_agent_file()` writes.

Every format is validated against one pydantic schema, `AgentConfig`, described [below](#agentconfig).

Use this when you want agent definitions to live as data — checked into git, edited by humans, generated by tools — rather than hard-coded in Python.

## Constructor

```python
from swarms import AgentLoader

loader = AgentLoader(concurrent=True, max_workers=8)
```

<ParamField path="concurrent" type="bool" default="True">
  Default for `load_agents_from_markdown()` when its own `concurrent` argument is not given. `AgentLoader(concurrent=False)` loads Markdown files one at a time.
</ParamField>

<ParamField path="max_workers" type="Optional[int]" default="None">
  Worker threads for concurrent Markdown loading and for building CSV, JSON, and YAML rows in `load_agents_from_csv()`. `None` uses twice the CPU count.
</ParamField>

## AgentConfig

`AgentConfig` is the pydantic model every loader validates against. Its field names are `Agent` parameters, and every field defaults to `None`: a field left unset falls back to the `Agent` default, not to a loader-specific one. Any model name is accepted.

```python
from swarms.structs.agent_loader import AgentConfig
```

| Field | Type | Accepted aliases |
|---|---|---|
| `agent_name` | `Optional[str]` | `name` |
| `agent_description` | `Optional[str]` | `description` |
| `system_prompt` | `Optional[str]`, at least 1 character | |
| `model_name` | `Optional[str]` | `model` |
| `temperature` | `Optional[float]`, 0.0 to 2.0 | |
| `max_loops` | `Optional[Union[PositiveInt, "auto"]]` | |
| `mcp_url` | `Optional[str]` | |
| `autosave` | `Optional[bool]` | |
| `dashboard` | `Optional[bool]` | |
| `verbose` | `Optional[bool]` | |
| `dynamic_temperature_enabled` | `Optional[bool]` | `dynamic_temperature` |
| `saved_state_path` | `Optional[str]` | |
| `user_name` | `Optional[str]` | |
| `retry_attempts` | `Optional[int]`, at least 1 | |
| `context_length` | `Optional[int]`, at least 1 | |
| `return_step_meta` | `Optional[bool]` | |
| `output_type` | `Optional[str]` | |
| `auto_generate_prompt` | `Optional[bool]` | |
| `streaming_on` | `Optional[bool]` | `streaming` |

`max_loops: auto` is accepted in every format. Keys the schema does not define are kept on the model (`model_extra`). `AgentConfig.agent_kwargs(extra=False)` returns the fields that are set as `Agent` keyword arguments; with `extra=True` it also returns the undefined keys. YAML loading uses `extra=True`, so unknown YAML keys pass through to `Agent` as custom parameters. Markdown, CSV, and JSON loading use `extra=False` and drop them.

## Methods

### auto()

Dispatch to the right loader based on file extension. The simplest entry point.

```python
def auto(self, file_path: str, *args, **kwargs)
```

**Parameters:**
- `file_path` (str): Path to a `.md`, `.yaml`, `.yml`, `.csv`, or `.json` file. The extension is matched in any case.
- `*args`, `**kwargs`: Forwarded to the underlying loader.

**Returns:** Whatever the matching loader returns: a `List[Agent]` for Markdown, CSV, and JSON, and the shape described under `load_agents_from_yaml()` for YAML.

**Raises:** `ValueError` for any other extension.

### load_single_agent()

Alias for `auto()` — loads a single file by dispatching on extension, and returns the same shape.

```python
def load_single_agent(self, *args, **kwargs)
```

### load_multiple_agents()

Apply `auto()` to a list of files. Each file may be a different format.

```python
def load_multiple_agents(
    self,
    file_paths: List[str],
    *args,
    **kwargs,
) -> list
```

**Parameters:**
- `file_paths` (List[str]): Paths to agent definition files.

**Returns:** One `auto()` result per input file, in order.

### load_agent_from_markdown()

Load a single agent from a Markdown file.

```python
def load_agent_from_markdown(
    self,
    file_path: str,
    **kwargs,
) -> Agent
```

`**kwargs` are `Agent` arguments that override the parsed configuration. Raises `ValueError` when the file fails to parse or the agent fails to build.

### load_agents_from_markdown()

Load multiple agents from one or more Markdown files.

```python
def load_agents_from_markdown(
    self,
    file_paths: Union[str, List[str]],
    concurrent: Optional[bool] = None,
    max_file_size_mb: float = 10.0,
    **kwargs,
) -> List[Agent]
```

<ParamField path="file_paths" type="Union[str, List[str]]">
  A single file, a directory (every `*.md` file in it, read in name order), or a list of file paths. Raises `FileNotFoundError` when a string path does not exist.
</ParamField>

<ParamField path="concurrent" type="Optional[bool]" default="None">
  Load files in parallel on `max_workers` threads when there is more than one. `None` uses the loader's `concurrent` setting. Agents are returned in file order either way.
</ParamField>

<ParamField path="max_file_size_mb" type="float" default="10.0">
  Files above this size are skipped.
</ParamField>

<ParamField path="**kwargs" type="Any">
  Override the parsed configuration for every agent, for example `model_name="gpt-5.4"`.
</ParamField>

A file that fails to parse or build is logged and skipped. Each file needs YAML frontmatter and a non-empty body, which becomes the system prompt. The frontmatter is validated as an [`AgentConfig`](#agentconfig), so any of its fields or aliases can be set there. `name` defaults to the file name without its extension and `description` to `"Agent loaded from markdown"`; every other unset field keeps the `Agent` default.

```markdown
---
name: Researcher
description: Finds and summarises sources
model_name: gpt-5.4
max_loops: auto
mcp_url: http://localhost:8000/sse
---
You research topics thoroughly and cite your sources.
```

The module also exports two shortcuts that build a default `AgentLoader`:

```python
from swarms import load_agent_from_markdown, load_agents_from_markdown

researcher = load_agent_from_markdown("agents/researcher.md", max_loops=3)
team = load_agents_from_markdown(["agents/a.md", "agents/b.md"], concurrent=True, max_file_size_mb=10.0)
```

### load_agents_from_yaml()

Load agents, and a `SwarmRouter` if one is configured, from a YAML file or string.

```python
def load_agents_from_yaml(
    self,
    yaml_file: Optional[str] = None,
    return_type: ReturnTypes = "auto",
    yaml_string: Optional[str] = None,
    **kwargs,
) -> Any
```

<ParamField path="yaml_file" type="Optional[str]" default="None">
  Path to the YAML definitions file. It holds either an `agents` list with an optional `swarm_architecture` section, or a bare list of agents, as `create_agent_file()` writes it. Raises `FileNotFoundError` when the file does not exist and `yaml_string` is not given.
</ParamField>

<ParamField path="return_type" type="ReturnTypes" default='"auto"'>
  Controls the return shape. One of `"auto"`, `"agents"`, `"both"`, `"swarm"`, `"run_swarm"`. Any other value raises `ValueError`.
</ParamField>

<ParamField path="yaml_string" type="Optional[str]" default="None">
  YAML content to use instead of reading `yaml_file`.
</ParamField>

<ParamField path="**kwargs" type="Any">
  `Agent` arguments applied to every loaded agent, overriding the file.
</ParamField>

Each agent entry is validated as an [`AgentConfig`](#agentconfig), and keys the schema does not define pass through to `Agent`. A nested `model:` block (`model_name`, `temperature`, `max_tokens`) is merged into the entry. An entry without a name is called `Agent_1`, `Agent_2`, and so on by position. `swarm_architecture` is passed to `SwarmRouter` as keyword arguments. Raises `ValueError` when no agents are defined.

```yaml
agents:
  - agent_name: Researcher
    system_prompt: You research topics thoroughly.
    model:
      model_name: gpt-5.4
      temperature: 0.3
  - agent_name: Writer
    system_prompt: You write clear reports.
swarm_architecture:
  name: Research-Pipeline
  swarm_type: SequentialWorkflow
  task: Summarise the current state of multi-agent research
```

| `return_type` | Returns |
|---|---|
| `"auto"` | A `SwarmRouter` when `swarm_architecture` is defined; otherwise one `Agent` if the file defines one agent, or a `List[Agent]` |
| `"agents"` | One `Agent` if the file defines one agent, otherwise a `List[Agent]` |
| `"both"` | A tuple of the `"auto"` result and the full agent list |
| `"swarm"`, `"run_swarm"` | Runs the `SwarmRouter` on `swarm_architecture.task` and returns its output |

<Warning>
`"swarm"` and `"run_swarm"` execute the swarm, which calls the model. They raise `ValueError` when the file has no `swarm_architecture` or no `task`.
</Warning>

### load_many_agents_from_yaml()

Load agents from a list of YAML files with per-file return type control.

```python
def load_many_agents_from_yaml(
    self,
    yaml_files: List[str],
    return_types: List[ReturnTypes] = ["auto"],
    **kwargs,
) -> list
```

Returns one `load_agents_from_yaml()` result per file. `return_types` needs one entry per file; the default `["auto"]` covers a single file and raises `IndexError` for more.

### load_agents_from_csv()

Load agents from a CSV, JSON, or YAML file of agent rows.

```python
def load_agents_from_csv(
    self,
    csv_file: Union[str, Path],
    **kwargs,
) -> List[Agent]
```

<ParamField path="csv_file" type="Union[str, Path]">
  Path to a `.csv`, `.json`, `.yaml`, or `.yml` file (any case). A JSON or YAML file holds a list of agent objects. Raises `FileNotFoundError` when the file is missing and `ValueError` for any other extension.
</ParamField>

<ParamField path="**kwargs" type="Any">
  `Agent` arguments applied to every loaded agent, overriding the file, for example `model_name="gpt-5.4"`.
</ParamField>

Each row is validated as an [`AgentConfig`](#agentconfig), so columns use its field names or aliases (`name`, `description`, `model`, `dynamic_temperature`, `streaming`). A blank CSV cell means unset, so the `Agent` default applies. Rows are built on `max_workers` threads and returned in file order. Rows that fail validation are printed and skipped.

### create_agent_file()

Validate agent configurations and write them to a CSV, JSON, or YAML file.

```python
def create_agent_file(
    self,
    file_path: Union[str, Path],
    agents: List[Union[BaseModel, Dict[str, Any]]],
) -> None
```

<ParamField path="file_path" type="Union[str, Path]">
  Destination file. Its extension picks the format: `.csv`, `.json`, `.yaml`, or `.yml`, in any case. Any other extension raises `ValueError`.
</ParamField>

<ParamField path="agents" type="List[Union[BaseModel, Dict[str, Any]]]">
  Agent configurations, as dicts or pydantic models. Each is validated as an [`AgentConfig`](#agentconfig) and written with its canonical field names; unset fields and keys the schema does not define are left out. Raises `pydantic.ValidationError` for an invalid configuration.
</ParamField>

### parse_markdown_file()

Lower-level: parse a Markdown file without building an agent.

```python
def parse_markdown_file(self, file_path: str) -> AgentConfig
```

Returns the parsed [`AgentConfig`](#agentconfig). Raises `FileNotFoundError` when the file is missing and `ValueError` when it has no frontmatter or fails validation.

## Usage Examples

### Auto-Dispatch on Extension

The shortest path — let `auto()` figure out the format.

```python
from swarms import AgentLoader

loader = AgentLoader()

# Each file uses its own format; auto() picks the right loader
research_agents = loader.auto("agents/research_team.yml")  # shape depends on return_type
support_agents = loader.auto("agents/support_squad.md")
sales_agents = loader.auto("agents/sales_reps.csv")
review_agents = loader.auto("agents/reviewers.json")
```

### Write and Read Back an Agent File

```python
from swarms import AgentLoader

loader = AgentLoader()

loader.create_agent_file("team.json", [
    {"agent_name": "Researcher", "system_prompt": "You research.", "max_loops": "auto"},
    {"agent_name": "Writer", "system_prompt": "You write.", "model_name": "gpt-5.4"},
])

# Overrides apply to every agent in the file
agents = loader.auto("team.json", model_name="gpt-5.4")
```

### Load Many Files in One Call

```python
from swarms import AgentLoader

loader = AgentLoader()

all_agents = loader.load_multiple_agents([
    "agents/support_squad.md",
    "agents/sales_reps.csv",
])

# One list of agents per file
for file_agents in all_agents:
    for agent in file_agents:
        print(agent.agent_name)
```

### Markdown with Concurrency Control

```python
from swarms import AgentLoader

loader = AgentLoader()

agents = loader.load_agents_from_markdown(
    file_paths=[
        "agents/researcher.md",
        "agents/writer.md",
        "agents/editor.md",
    ],
    concurrent=True,
    max_file_size_mb=5.0,
)
```

### Compose with a Swarm

```python
from swarms import AgentLoader, SequentialWorkflow

loader = AgentLoader()

# The file defines two or more agents
agents = loader.load_agents_from_yaml(
    "agents/research_pipeline.yaml", return_type="agents"
)

workflow = SequentialWorkflow(agents=agents, max_loops=1)
result = workflow.run("Summarize the current state of multi-agent research")
```
