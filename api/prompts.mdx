## Overview

The `swarms.prompts` module provides tools for creating, managing, and versioning prompts with comprehensive history tracking, autosaving capabilities, and integration with agent systems.

`swarms.prompts` exports 12 names: the `Prompt` class, eight prompt strings (`AUTO_AGENT_BUILDER_SYSTEM_PROMPT`, `CODE_INTERPRETER`, `DOCUMENTATION_WRITER_SOP`, `FINANCE_AGENT_PROMPT`, `GROWTH_AGENT_PROMPT`, `LEGAL_AGENT_PROMPT`, `OPERATIONS_AGENT_PROMPT`, `PRODUCT_AGENT_PROMPT`), and three autonomous-prompt functions. All of them are re-exported from the top-level `swarms` package. The prompts that framework structures use internally live in their own modules; see [Prompts used by framework structures](#prompts-used-by-framework-structures).

## Prompt Class

A Pydantic model for managing prompts with version control, edit history, and autosaving features.

```python
from swarms import Prompt

prompt = Prompt(
    name="analysis_prompt",
    description="Financial analysis prompt",
    content="Analyze the following financial data...",
    autosave=True,
    autosave_folder="prompts"
)
```

### Constructor

<ParamField path="id" type="str" default="generate_id('prompt')">
  Identifier for the prompt, also used in the autosave file name. Each prompt created without an `id` gets a new one of the form `prompt-<32 hex chars>`
</ParamField>

<ParamField path="name" type="str" default="prompt">
  Name of your prompt
</ParamField>

<ParamField path="description" type="str" default="Simple Prompt">
  Description of the prompt
</ParamField>

<ParamField path="content" type="str" required>
  The main content of the prompt. Leading and trailing whitespace is stripped, and at least 1 character must remain
</ParamField>

<ParamField path="created_at" type="str" default="current_time">
  Timestamp when the prompt was created
</ParamField>

<ParamField path="last_modified_at" type="str" default="current_time">
  Timestamp when the prompt was last modified
</ParamField>

<ParamField path="edit_count" type="int" default="0">
  Number of times the prompt has been edited
</ParamField>

<ParamField path="edit_history" type="List[str]" default="[]">
  History of all prompt versions
</ParamField>

<ParamField path="autosave" type="bool" default="False">
  Save the prompt to disk on creation and after every edit or rollback
</ParamField>

<ParamField path="autosave_folder" type="str" default="prompts">
  Folder path within WORKSPACE_DIR for autosaving
</ParamField>

### Methods

#### edit_prompt

Edit the prompt content and update version control.

```python
prompt.edit_prompt("Updated prompt content here")
```

<ParamField path="new_content" type="str" required>
  The updated content of the prompt
</ParamField>

It appends the new content to `edit_history`, increments `edit_count`, and updates `last_modified_at`.

**Raises:**
- `ValueError`: If the new content is identical to the current content

#### rollback

Roll back the prompt to a previous version. The content becomes `edit_history[version]` and `edit_count` is set to `version`. `edit_history` is not trimmed, so you can roll forward again.

```python
# Rollback to the first version
prompt.rollback(version=0)
```

<ParamField path="version" type="int" required>
  The version index to roll back to (0 is the first version)
</ParamField>

**Raises:**
- `IndexError`: If the version number is out of range

#### get_prompt

Return the current prompt content as a string.

```python
content = prompt.get_prompt()
print(content)
```

<ResponseField name="return" type="str">
  The current prompt content
</ResponseField>

#### return_json

Return the prompt as a JSON string.

```python
json_data = prompt.return_json()
print(json_data)
```

<ResponseField name="return" type="str">
  JSON representation of the prompt with all metadata
</ResponseField>

#### add_tools

Intended to append the OpenAI schemas of a list of functions to the prompt content.

<ParamField path="tools" type="List[Callable]" required>
  List of callable functions to add as tools
</ParamField>

<Warning>
`add_tools()` currently raises `TypeError`, because it concatenates the schema dict to the content string. It appends two newlines to `content` before it fails. Until it is fixed, build the schema yourself and pass it to `edit_prompt()`:

```python
import json

from swarms import BaseTool

def double(x: int) -> int:
    """Double the input.

    Args:
        x: The number to double.

    Returns:
        Twice the input.
    """
    return x * 2

schema = BaseTool(tools=[double]).convert_tool_into_openai_schema()
prompt.edit_prompt(prompt.get_prompt() + "\n\n" + json.dumps(schema, indent=2))
```
</Warning>

### Autonomous Agent Prompts

These build the system prompt an agent uses with `max_loops="auto"`. See [Autonomous mode](/agents/autonomous-mode).

#### autonomous_agent_system_prompt

Return the base autonomous agent system prompt. Its `Time:` line holds the date and time when you call it.

```python
from swarms import autonomous_agent_system_prompt

prompt = autonomous_agent_system_prompt()
```

<Warning>
The `AUTONOMOUS_AGENT_SYSTEM_PROMPT` constant has been removed. As a module-level string, it froze the time at import, so long-running processes told every agent the process start time. Call `autonomous_agent_system_prompt()` instead.
</Warning>

#### get_autonomous_agent_prompt

Return the autonomous agent prompt, matched to whether the agent has the `think` tool.

```python
from swarms import get_autonomous_agent_prompt

prompt = get_autonomous_agent_prompt(include_think_tool=True)
```

<ParamField path="include_think_tool" type="bool" default="False">
  Whether the agent has the `think` tool. When `False`, a section is appended telling the model the tool is unavailable and to reason inline instead
</ParamField>

#### get_autonomous_agent_prompt_with_context

Generate an autonomous agent prompt customized with agent identity and available tools.

```python
from swarms import get_autonomous_agent_prompt_with_context

prompt = get_autonomous_agent_prompt_with_context(
    agent_name="MarketAnalyst",
    agent_description="Analyzes financial markets with a focus on tech stocks",
    available_tools=["search_web", "get_stock_price"],
)
```

<ParamField path="agent_name" type="str" default="None">
  Name of the agent to embed in the prompt
</ParamField>

<ParamField path="agent_description" type="str" default="None">
  Description of the agent's role to embed in the prompt
</ParamField>

<ParamField path="available_tools" type="list" default="None">
  List of tool names available to the agent. The first 20 are listed, followed by a count of the rest
</ParamField>

The agent name replaces the opening "You are an elite autonomous agent" line, and the description and tools are appended as `## AGENT ROLE` and `## AVAILABLE TOOLS` sections. This function always keeps the `think` tool instructions.

## Prompts used by framework structures

Framework structures keep their prompts in dedicated modules under `swarms/prompts`. They are not exported from `swarms.prompts`, so import them from the module path. Read them to see what a structure tells its agents, or to build a variant.

| Module | Names | Used by |
|---|---|---|
| `swarms.prompts.agent_system_prompts` | `AGENT_SYSTEM_PROMPT_3`, `build_agent_system_prompt()` | Opt in with `Agent(system_prompt=build_agent_system_prompt())`. `Agent` sends no system prompt by default |
| `swarms.prompts.autonomous_agent_prompt` | `autonomous_agent_system_prompt()`, `get_autonomous_agent_prompt()`, `get_autonomous_agent_prompt_with_context()` | `Agent` with `max_loops="auto"` |
| `swarms.prompts.groupchat_prompt` | `GROUPCHAT_DECIDE_PROMPT` | [GroupChat](/api/group-chat), to ask each agent whether to speak |
| `swarms.prompts.llm_council_prompts` | `get_gpt_councilor_prompt()`, `get_gemini_councilor_prompt()`, `get_claude_councilor_prompt()`, `get_grok_councilor_prompt()`, `get_chairman_prompt()`, `get_evaluation_prompt(query, responses, evaluator_name)`, `get_synthesis_prompt(query, original_responses, evaluations, id_to_member)` | [LLMCouncil](/api/llm-council) |
| `swarms.prompts.tree_of_thoughts_prompts` | `TREE_OF_THOUGHTS_SYSTEM_PROMPT` and the `TOT_*` templates | [Tree of Thoughts](/agents/tree-of-thoughts) |

### Default agent system prompt

`AGENT_SYSTEM_PROMPT_3` is the default agent persona without a timestamp. `build_agent_system_prompt()` returns the same text with a `Time:` line for the current date and time. `Agent` no longer uses it by default: an agent built without `system_prompt` sends no system message. Pass `system_prompt=build_agent_system_prompt()` to get the old persona, with the time it was built.

```python
from swarms.prompts.agent_system_prompts import build_agent_system_prompt

prompt = build_agent_system_prompt()
```

### Groupchat decision prompt

`GROUPCHAT_DECIDE_PROMPT` is formatted with `agent_name`, `other_agents`, `sender` and `message`. It asks the agent to assess the discussion, then call `respond` once with a calibrated score from 0.0 to 1.0 and its reply. It says what deserves a high, moderate or low score, gives a calibration scale, and says to answer 0.0 with an empty message when there is nothing distinct to add. It also tells the agent not to inflate the score to keep the conversation going.

### LLM council prompts

The four councilor personas, the chairman prompt, and the peer-evaluation and synthesis builders live in `swarms.prompts.llm_council_prompts`. `swarms.structs.llm_council` imports them back, so existing imports from the struct module keep working.

```python
from swarms.prompts.llm_council_prompts import get_evaluation_prompt

prompt = get_evaluation_prompt(
    query="Which database should we use?",
    responses={"A": "Postgres, because...", "B": "SQLite, because..."},
    evaluator_name="Claude-Councilor",
)
```

## Example: Complete Prompt Management

```python
import json
import os

# Set before importing swarms, which resolves WORKSPACE_DIR on import
os.environ["WORKSPACE_DIR"] = "./workspace"

from swarms import BaseTool, Prompt

# Create a prompt with autosave
prompt = Prompt(
    name="market_analysis",
    description="Financial market analysis prompt",
    content="""You are a financial analyst. Analyze the following:
    1. Market trends
    2. Risk factors
    3. Investment opportunities
    """,
    autosave=True,
    autosave_folder="financial_prompts"
)

# Edit the prompt
prompt.edit_prompt("""
You are an expert financial analyst specializing in equity markets.

Analyze the following aspects:
1. Current market trends and momentum
2. Key risk factors and hedging strategies
3. High-conviction investment opportunities
4. Portfolio allocation recommendations

Provide detailed analysis with supporting data.
""")

print(f"Edit count: {prompt.edit_count}")  # 1
print(f"Total versions: {len(prompt.edit_history)}")  # 2

# Append a tool schema to the prompt
def calculate_sharpe_ratio(returns: float, risk_free_rate: float, std_dev: float) -> float:
    """Calculate Sharpe ratio for investment analysis.

    Args:
        returns: Portfolio return.
        risk_free_rate: Risk-free rate.
        std_dev: Standard deviation of returns.

    Returns:
        The Sharpe ratio.
    """
    return (returns - risk_free_rate) / std_dev

schema = BaseTool(tools=[calculate_sharpe_ratio]).convert_tool_into_openai_schema()
prompt.edit_prompt(prompt.get_prompt() + "\n\n" + json.dumps(schema, indent=2))

# Rollback if needed
prompt.rollback(version=0)  # Back to original version

# Get the current prompt
current = prompt.get_prompt()
print(current)

# Export as JSON
json_export = prompt.return_json()
print(json_export)
```

## Best Practices

1. **Enable autosave**: Always enable autosave for important prompts to prevent data loss
2. **Use descriptive names**: Give prompts clear, descriptive names for easy identification
3. **Version control**: Leverage the built-in version control to track prompt evolution
4. **Add context**: Include detailed descriptions to document the prompt's purpose
5. **Organize by folder**: Use the `autosave_folder` parameter to organize prompts by category
6. **Regular rollbacks**: Test different prompt versions using rollback functionality

## Thread safety

`Prompt` does not lock. Edits, rollbacks and autosaves are plain attribute updates and file writes, so guard a `Prompt` shared across threads with your own `threading.Lock`.

## Autosave Behavior

When autosave is enabled:
1. Prompts are saved to `{WORKSPACE_DIR}/{autosave_folder}/prompt-id-{id}.json`. When `WORKSPACE_DIR` is unset, importing `swarms` sets it to `./agent_workspace`
2. Creating the prompt triggers a save
3. Each edit automatically triggers a save
4. Rollback operations also trigger saves
5. The entire prompt state (including history) is preserved

## Integration with Agents

```python
from swarms import FINANCE_AGENT_PROMPT, Agent, Prompt

# Using pre-built prompts
agent1 = Agent(
    agent_name="Financial-Analyst",
    system_prompt=FINANCE_AGENT_PROMPT,
    model_name="gpt-5.4"
)

# Using custom Prompt class
custom_prompt = Prompt(
    name="custom_analyst",
    content="You are a specialized quantitative analyst...",
    autosave=True
)

agent2 = Agent(
    agent_name="Quant-Analyst",
    system_prompt=custom_prompt.get_prompt(),
    model_name="gpt-5.4"
)
```
