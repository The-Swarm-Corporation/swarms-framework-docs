## Overview

The `SpreadSheetSwarm` processes tasks concurrently across multiple agents and automatically saves execution metadata to CSV files. It supports loading agent configurations from CSV files and running tasks either from configuration or on-demand.

## Installation

```bash
pip install -U swarms
```

## Attributes

<ParamField path="name" type="str" default="Spreadsheet-Swarm">
  The name of the swarm
</ParamField>

<ParamField path="description" type="str" default="A swarm that processes tasks concurrently...">
  The description of the swarm
</ParamField>

<ParamField path="agents" type="List[Agent]" default="None">
  The agents participating in the swarm. Required — the constructor runs a reliability check before any CSV loading happens, so a non-empty `agents` list must be supplied even if `load_path` is also set
</ParamField>

<ParamField path="autosave" type="bool" default="True">
  Whether to enable autosave of swarm metadata
</ParamField>

<ParamField path="save_file_path" type="str" default="None">
  The file path to save the swarm metadata as a CSV file (auto-generated if None)
</ParamField>

<ParamField path="max_loops" type="int" default="1">
  The number of times to repeat the swarm tasks
</ParamField>

<ParamField path="load_path" type="str" default="None">
  Path to a CSV file containing agent definitions and tasks (`agent_name`, `system_prompt`, `description`, `task`, `model_name`, etc.). Calling `load_from_csv()` instantiates a new `Agent` for each row, appends it to `self.agents`, and registers its task in `self.agent_tasks`.
</ParamField>

<ParamField path="verbose" type="bool" default="False">
  Enable verbose logging
</ParamField>

## Methods

### run()

Run the swarm with the specified task.

```python
def run(self, task: str = None, *args, **kwargs) -> dict
```

**Parameters:**
- `task` (str): The task to be executed by the swarm. If None, uses tasks from config

**Returns:** Dictionary containing run summary with outputs and metadata

### run_from_config()

Run all agents with their configured tasks concurrently.

```python
def run_from_config(self) -> dict
```

**Returns:** Dictionary containing execution summary

### load_from_csv()

Load agent configurations and task mappings from the CSV file specified in `load_path`.

```python
def load_from_csv(self)
```

For each row in the CSV file, `load_from_csv()`:
1. Records `self.agent_tasks[agent_name] = task`.
2. Instantiates a new `Agent` configured with the row parameters (`system_prompt`, `description`, `model_name`, `max_loops`, `docs`, `user_name`, `stopping_token`).
3. Appends the newly created `Agent` to `self.agents`.

Expected CSV format:
```csv
agent_name,description,system_prompt,task,model_name,max_loops
```

### export_to_json()

Export the swarm outputs to JSON.

```python
def export_to_json(self) -> str
```

**Returns:** JSON string representation of swarm outputs

### data_to_json_file()

Save the swarm outputs (via `export_to_json()`) to a JSON file in the workspace directory. Called automatically after each run when `autosave=True`.

```python
def data_to_json_file(self)
```

**Returns:** None. Writes the JSON metadata file to disk.

## Usage Examples

### Basic Usage with Agents

```python
from swarms import Agent, SpreadSheetSwarm

# Create agents
agents = [
    Agent(
        agent_name="Research-Agent",
        system_prompt="You are a research agent.",
        model_name="openai/gpt-5.4",
    ),
    Agent(
        agent_name="Analysis-Agent",
        system_prompt="You are an analysis agent.",
        model_name="openai/gpt-5.4",
    ),
]

# Create swarm
swarm = SpreadSheetSwarm(
    name="My-Swarm",
    agents=agents,
    max_loops=1,
    autosave=True
)

# Run with a task
result = swarm.run("Analyze the latest AI trends")

print(result)
```

### Load from CSV Configuration

<Warning>
  `agents` must be non-empty at construction due to the swarm reliability preflight check. Note that `load_from_csv()` dynamically instantiates and appends a new `Agent` for every row in the CSV into `self.agents`. If you construct the swarm with agents whose names match rows in the CSV, `run_from_config()` will match both the existing and the newly instantiated agent, causing the task to execute multiple times.
</Warning>

#### Option A: Dynamically Instantiating Agents from CSV

Create `agents_config.csv` with the full agent specifications and tasks:
```csv
agent_name,description,system_prompt,task,model_name
CSV-Researcher,Research specialist,You are a research agent.,Research quantum computing,openai/gpt-4o
CSV-Analyst,Data analyst,You are an analysis agent.,Analyze the research findings,openai/gpt-4o
```

Construct the swarm with an initial bootstrap agent, load the CSV to instantiate the workflow agents, and run:
```python
from swarms import Agent, SpreadSheetSwarm

# Initial bootstrap agent to satisfy swarm construction checks
bootstrap_agent = Agent(
    agent_name="Coordinator",
    system_prompt="Swarm coordinator",
    model_name="openai/gpt-4o"
)

swarm = SpreadSheetSwarm(
    name="CSV-Swarm",
    agents=[bootstrap_agent],
    load_path="agents_config.csv",
    max_loops=1
)

# Instantiates CSV-Researcher and CSV-Analyst and sets their tasks
swarm.load_from_csv()

# Runs all agents with registered tasks (CSV-Researcher and CSV-Analyst)
result = swarm.run_from_config()
```

#### Option B: Mapping Tasks to Existing Pre-configured Agents

If you prefer to define and customize your `Agent` instances in Python code without appending duplicate instances from CSV:

```python
from swarms import Agent, SpreadSheetSwarm

agents = [
    Agent(agent_name="Research-Agent", system_prompt="You are a research agent.", model_name="openai/gpt-4o"),
    Agent(agent_name="Analysis-Agent", system_prompt="You are an analysis agent.", model_name="openai/gpt-4o"),
]

swarm = SpreadSheetSwarm(
    name="Custom-Swarm",
    agents=agents,
    max_loops=1
)

# Map tasks directly to existing agents by agent_name
swarm.agent_tasks["Research-Agent"] = "Research quantum computing breakthroughs"
swarm.agent_tasks["Analysis-Agent"] = "Analyze key findings and technical feasibility"

result = swarm.run_from_config()
```

### Multiple Loops

```python
# Run each agent multiple times
swarm = SpreadSheetSwarm(
    agents=agents,
    max_loops=3  # Each agent runs 3 times
)

result = swarm.run("Process this task multiple times")
```

### Custom Save Path

```python
swarm = SpreadSheetSwarm(
    name="Custom-Swarm",
    agents=agents,
    save_file_path="./results/swarm_outputs.csv",
    autosave=True
)

result = swarm.run("Custom task")
```

### Export Results

```python
# Run swarm
result = swarm.run("Some task")

# Export to JSON
json_output = swarm.export_to_json()
print(json_output)

# Results are automatically saved to CSV if autosave=True
```

## Output Format

The `run()` method returns a dictionary:

```python
{
    "run_id": "spreadsheet_swarm_run_abc123",
    "name": "My-Swarm",
    "description": "A swarm that processes tasks...",
    "start_time": "2024-01-01T12:00:00",
    "end_time": "2024-01-01T12:05:00",
    "tasks_completed": 6,
    "number_of_agents": 3,
    "outputs": [
        {
            "agent_name": "Research-Agent",
            "task": "Analyze the latest AI trends",
            "result": "...",
            "timestamp": "2024-01-01T12:01:00"
        },
        # ... more outputs
    ]
}
```

## CSV Output Format

Results are automatically saved to CSV with these columns:

```csv
Run ID,Agent Name,Task,Result,Timestamp
abc-123,Research-Agent,Analyze trends,...,2024-01-01T12:00:00
abc-123,Analysis-Agent,Analyze trends,...,2024-01-01T12:00:05
```

## Features

- **Concurrent Execution**: All agents run tasks in parallel for maximum performance
- **Automatic CSV Logging**: All executions are logged to CSV files automatically
- **CSV Configuration**: Load agent configurations from CSV files
- **Multiple Loops**: Run each agent multiple times with `max_loops`
- **Workspace Integration**: Automatically uses workspace directory from environment
- **JSON Export**: Export results to JSON format
- **Metadata Tracking**: Tracks timestamps, run IDs, and execution metadata
