Ce guide adapte les premiers exemples du [guide de démarrage en anglais](/quickstart).
Vous allez créer un agent, lui confier une tâche, puis relier deux agents dans un
workflow séquentiel. Les identifiants Python restent en anglais pour faciliter
la comparaison avec la référence de l'API.

<Note>
  Avant de commencer, [installez Swarms](/installation) et
  [configurez votre environnement](/environment-setup), notamment la clé API
  du fournisseur choisi. Ces pages sont en anglais. Les exemples appellent un
  modèle externe : son utilisation peut être facturée par le fournisseur.
</Note>

## Créez votre premier agent

Un **agent** associe un modèle de langage à une configuration et peut utiliser
des outils et une mémoire. Copiez cet exemple dans un fichier Python :

```python
from swarms import Agent

agent = Agent(
    agent_name="Assistant",
    model_name="gpt-5.4",
    max_loops=1,
)

response = agent.run(
    "Explique en français trois avantages des systèmes multi-agents."
)
print(response)
```

`model_name` choisit le modèle. Utilisez un modèle auquel votre compte fournisseur
a accès. `max_loops=1` limite le nombre d'itérations de raisonnement de l'agent ;
ce paramètre ne constitue pas un plafond de dépenses. La méthode `run()` reçoit
votre tâche et renvoie le résultat, affiché ici avec `print()`.

## Faites collaborer deux agents

Un **swarm** regroupe plusieurs agents. Dans cet exemple, le premier prépare une
synthèse et le second s'en sert pour rédiger un article. Aucun outil de recherche
web n'est configuré : la synthèse s'appuie sur les capacités du modèle.

```python
from swarms import Agent, SequentialWorkflow

researcher = Agent(
    agent_name="Researcher",
    system_prompt="Prépare une synthèse du sujet fourni, en français.",
    model_name="gpt-5.4",
    max_loops=1,
)

writer = Agent(
    agent_name="Writer",
    system_prompt="Transforme la synthèse reçue en un court article en français.",
    model_name="gpt-5.4",
    max_loops=1,
)

workflow = SequentialWorkflow(agents=[researcher, writer])
result = workflow.run("Les usages des systèmes multi-agents")
print(result)
```

`system_prompt` décrit le rôle de chaque agent. `SequentialWorkflow` exécute les
agents dans l'ordre indiqué : le premier traite la tâche, puis sa sortie est
transmise au suivant. Cette organisation convient aux étapes qui dépendent les
unes des autres, comme la synthèse puis la rédaction.

Pour des tâches indépendantes à exécuter simultanément, consultez plutôt
[ConcurrentWorkflow](/architectures/concurrent-workflow).

## Résolvez les problèmes courants

- **Authentification refusée :** vérifiez la configuration de votre clé API dans
  l'environnement. Ne publiez pas votre clé dans un rapport d'erreur.
- **Modèle introuvable :** vérifiez son identifiant et les autorisations de votre
  compte. Consultez les [fournisseurs de modèles](/integrations/model-providers).
- **Limite de requêtes atteinte :** vérifiez les quotas du fournisseur. Réduire
  les itérations peut limiter les appels, sans supprimer toutes les causes de
  limitation.
