Swarms ships often. Recent major versions have landed roughly every four to seven weeks, with patch releases in between. Each major version gets a dedicated changelog page covering its patch releases: what changed and how to adopt it.

> Apache 2.0 · [github.com/kyegomez/swarms](https://github.com/kyegomez/swarms)

Changes merged to `master` after the latest release are listed under **Unreleased** on the newest version's page. Check the version you have installed with:

```bash
python -c "import swarms; print(swarms.__version__)"
```

## Staying up to date

To get the latest release, upgrade via pip:

```bash
pip install -U swarms
```

Release notes are published here with each version. For day-to-day development activity between releases, follow the [GitHub repository](https://github.com/kyegomez/swarms).
