## Prerequisites

- **Python 3.10 or higher**
- An API key for at least one provider, or a local server such as Ollama

## Install the package

<CodeGroup>

```bash pip
pip install -U routehub
```

```bash uv
uv add routehub
```

```bash poetry
poetry add routehub
```

```bash From source
git clone https://github.com/The-Swarm-Corporation/RouteHub.git
cd RouteHub
pip install -e .
```

</CodeGroup>

RouteHub has three direct dependencies: `openai`, `pydantic` and `tiktoken`. It works with openai 2.x and 3.x.

## Faster JSON with the `fast` extra

The `fast` extra installs [orjson](https://github.com/ijl/orjson), which RouteHub uses for JSON encoding and decoding when it is available.

<CodeGroup>

```bash pip
pip install "routehub[fast]"
```

```bash uv
uv add "routehub[fast]"
```

</CodeGroup>

<Tip>
  Set `ROUTEHUB_USE_ORJSON=0` to fall back to the standard `json` module without uninstalling orjson.
</Tip>

## Set a provider key

RouteHub reads each provider's key from its environment variable on every call. Set the ones you need:

```bash
export OPENAI_API_KEY="sk-..."
export ANTHROPIC_API_KEY="sk-ant-..."
export GEMINI_API_KEY="..."
export GROQ_API_KEY="gsk_..."
```

You can also pass `api_key=` to any call. See [Providers](/routehub/providers) for every variable name.

<Warning>
  Keep keys in a `.env` file or a secrets manager and never commit them. RouteHub never writes keys to logs, including with `set_verbose=True`.
</Warning>

## Verify the install

`mock_response` returns a real `ChatCompletion` without a network call or an API key, so you can check the install offline:

```python
import routehub

print(routehub.__version__)

response = routehub.completion(
    model="gpt-5.4-mini",
    messages=[{"role": "user", "content": "ping"}],
    mock_response="pong",
)
print(response.choices[0].message.content)  # pong
```

## Use RouteHub with Swarms

Install Swarms with its `fast` extra and every agent makes its model calls through RouteHub instead of LiteLLM, with no code changes:

```bash
pip install -U "swarms[fast]"
```

The extra requires RouteHub 0.2.0 or newer, with RouteHub's own `fast` extra, and also installs rustworkx for `GraphWorkflow(backend="rustworkx")`. Swarms picks RouteHub whenever it is installed. Set `SWARMS_LLM_BACKEND=litellm` to force LiteLLM, or `routehub` to require RouteHub. See [Installation](/installation) and [Environment setup](/environment-setup).

On RouteHub, local OpenAI-compatible servers need `/v1` in the agent's `llm_base_url`, for example `http://localhost:11434/v1` for Ollama.
